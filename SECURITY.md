# Security Policy

## Supported versions

Only the latest version on the `main` branch is currently supported.

## Reporting a vulnerability

Please do not disclose security vulnerabilities in public issues. Contact the repository owner privately through GitHub's security advisory reporting feature:

https://github.com/Sirkho/Quanterminal/security/advisories/new

Include steps to reproduce, affected components, and potential impact. Do not include real API keys, tokens, or personal data in reports.
